# π0.5 FrameSamp+Modul：实现总览

> 完整记录：[π0.5 FrameSamp+Modul 完整实现记录](../99_详细记录/02_π0.5_FrameSamp_Modul_完整记录.md)

## 1. 核心结论

实现包含两条独立视觉路径：

```text
当前三路 RGB → 原 π0.5 SigLIP/VLM prefix

历史 cam_high → 离线 SigLIP → 4×4 pooling → FrameSamp
            → 3D 时间/空间位置编码 → 512 memory tokens
            → action expert 的 MemoryAttention 与 modulation
```

历史帧不是第四张 VLM 图片，也不会增加 PaliGemma prefix 的图像数量；它们只影响 action expert。

## 2. 固定配置

| 配置 | 数值 |
|---|---:|
| `framesamp_budget` | 512 tokens |
| 每帧保留 token | 16（4×4 pooling） |
| 最大历史帧数 | 32 |
| SigLIP 特征维度 | 2048 |
| 位置编码维度 | 768 |
| memory / action expert 宽度 | 1024 |

## 3. 训练数据流

1. 离线读取 `cam_high` 帧，用 SigLIP 提取 patch 特征。
2. 对每帧做 4×4 mean pooling，得到 16 个视觉 token。
3. 按时间均匀采样历史帧；不足 32 帧时右侧 padding 到 512 token。
4. 生成 3D 时间/空间位置编码和 padding mask。
5. 数据变换链保留 memory 字段，传入 `PerceptualMemory`，投影到 1024 维。
6. action expert 每层执行 memory cross-attention，再进行 scale/shift modulation。
7. 只对 flow-matching action loss 反向传播；原 VLM expert 不使用 memory。

## 4. 时间采样

训练配置为 `obs_steps=6`、`obs_interval_seconds=1.0`。FrameSamp 随当前帧位置变化，把历史帧均匀映射到固定预算。采样规则、边界帧和 mask 是复现的关键，不能只记录最终的 512 token。

## 5. 关键实现判断

- memory 的 padding mask 必须贯穿 dataset、模型输入和 cross-attention；只在数据侧 padding 会把无效 token 当成视觉条件。
- 位置编码描述的是历史 token 的时间和图像空间位置，不能替代相机标定或机器人状态。
- 离线特征缓存降低训练成本，但引入缓存完整性、版本和断点续跑要求。
- 当前实现重点是训练侧；推理侧仍需补齐历史帧缓存、特征读取和动作执行节奏。
